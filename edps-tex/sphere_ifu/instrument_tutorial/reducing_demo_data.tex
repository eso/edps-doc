Exported products are organized by `DATASET` (named as the first scientific exposure of the dataset), and `TIMESTAMP` (time of start of reduction). 

The final product saved in the specified directory is the wavelength-calibrated datacube, with name format \texttt{DATACUBE\_} followed by the archive file name (corresponding to header keyword \texttt{ARCFILE}).
