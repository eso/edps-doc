Exported products are organized by `DATASET` (named as the first
scientific exposure of the dataset), and `TIMESTAMP` (time of start of
reduction)

The final products saved in the specified directory are: 

\begin{itemize}

\item SPECTRUM\_LSS/MOS/MXU\_2D\_... - 2-dimensional science frame, sky-subtracted and flux-calibrated.

\item SPECTRUM\_LSS\_... - 1-dimensional extracted, flux-calibrated spectra (Phase3 compliant).
\end{itemize}
